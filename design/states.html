冲突的三种来源。① 目标名在磁盘已存在；② 两条规则产出同一新名（如“替换”后又“添加”）；③ 仅大小写变化——在 macOS 默认 APFS 上会被视为同名，Windows 上则允许。
预览是纯函数计算，读取目录但不写入磁盘；正式执行才进入两阶段改名，中途失败会回滚已改项。

错误与跨平台提示

每条错误都说清“为什么 + 怎么办”，并给出可继续的出口，而不是只有一个“确定”。
权限 / 长路径

无法重命名：目标位于受保护目录

Windows · 错误码 ERROR_ACCESS_DENIED (5)

文件C:\Program Files\旅行\DSC_0104.JPG 操作Rename(temp) → Rename(final) 原因目录需要管理员权限，当前进程为普通权限（asInvoker） 影响仅此 1 项，其余 115 项可继续
建议。把文件复制到用户目录（如 ~/Pictures）后更名；或以管理员权限重新启动应用处理该目录。
提升权限会弹出系统 UAC / macOS 授权框；应用申请的最小权限仅为所选目录的读写。
该错误已记录到日志，可在“历史”中复查
文件名含平台保留字符
“2024:旅行”在 macOS / Linux 中 : 非法；预览已标红，替换为 _ 后可继续。
路径长度 268 > 260
Windows 未启用长路径支持；可缩短目标目录，或在设置中开启“长路径兼容模式”。
文件被其他程序占用
报告.docx 正被 Word 打开（共享冲突），关闭后可重试。
大小写敏感性差异
本次仅将 .JPG 改为 .jpg：Windows 视为同名，macOS 需先改成临时名再落盘。
兼容性提示不阻断执行：黄色可继续，红色必须修改。原版的“长文件名警告 / 属性警告 / 权限设置”窗体语义在这里合并为同一套提示。

01保留了什么

原版的确认环节一个都没删：冲突、超长文件名、只读属性、权限不足、撤销确认。老用户仍然先看结果再落盘，风险提示仍然出现在执行之前。

02改了什么

模态弹窗改为“预览面板 + 非阻塞提示”：一次看清 4 类结果，错误可跳过、可重试、可继续；撤销从“一个按钮”变成可见的批次历史。

03为什么这样改

批量操作最怕“弹窗打断—逐条确认”；把判断前置到预览、把异常收敛到统一提示，既保留审慎，又让 100+ 文件的处理不再手忙脚乱。
