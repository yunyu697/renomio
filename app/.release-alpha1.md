## Renomio 1.2.0-alpha1（预发布）

`1.1.0` 之后的第一个 minor 版本（alpha 序号从 1 重新开始）。本版把界面收进角色令牌体系，并补了一批列表操作。**alpha 阶段，未做真机点验**。

### 界面与交互

- **工具栏图标折叠**：宽度不足时按钮标签降级成图标，只保留一行；切换点按「标签版自然宽度刚好放不下」那一档实测，不折行、不压缩按钮高度与内边距。
- **列表页头**：新增状态筛选弹层（全部 / 可执行 / 冲突 / 未变更等）与 `排序重置`；`重复扫描`、`移除选中`、`清空` 收进 `更多操作` 菜单，页头不再挤成两行。
- **检查器**：页头开关带选中计数，展开后展示选中项与批次信息。
- **规则栏空态**：0 条规则且无冲突时收成 56px 收缩轨，不再空占一整屏；轨上的按钮直接变成 `+ 添加规则`，点击先展开面板再弹菜单。
- **恢复添加顺序**：`恢复添加顺序` 按文件加入列表时的顺序重排（旧会话没有序号时置灰）；配 `撤销恢复`，可回到恢复前的顺序。未手动排序时不产生可撤销记录。
- **状态栏文案去重**：删掉与「本地离线 · 不上传」重复的「本地运行 · 离线」，「仅预览模式」保留（它是状态不是说明）。
- 行高统一到 44，12 处越界控件（行内上移/下移、Toast 关闭、输入框、折叠箭头）回到角色档内，点击区域未缩小。

### 设计体系

- **角色令牌落地**：字号、控件高度、圆角、间距改按角色取档（`--ds-font-*` / `--ds-control-*` / `--ds-radius-*`），不再散落一次性数值；三个未写 `font-size` 的图标控件补齐角色值。
- **裸色值清理**：清掉 37 处语义裸色值——2 处 hex、33 处 rgba 派生边框、2 处 `var(--success, #1a8a4a)` 死兜底（兜底值去掉，只留令牌）。logo 描画与调色板预览圆点属有意例外，保留。

### 验证

- `npm run build`（`tsc --noEmit` + `vite build`）：通过。
- `npm run test:e2e`：**257 通过 / 0 失败**（1440×900 与 1100×640@1.5x 两档视口）。
- `npm run version:check`、`node scripts/check-version.mjs --tag v1.2.0-alpha1`、`npm run version:selftest`（16/16）：通过。

### 包

三平台 14 个资产（Windows NSIS/MSI、Linux deb/AppImage、macOS dmg/`Renomio.app.tar.gz`/`.app.zip`）连同 updater `.sig` 与 `SHA256SUMS` 发布在本 Release；`updates` Release 的 `latest.json` 已指向本版。逐文件 SHA-256 见 Release 附件 `SHA256SUMS`。
