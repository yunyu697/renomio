## Renomio 1.2.0-alpha3（预发布）

这一版是界面重构（B 方案：macOS 走 Apple HIG，Windows 保留习惯但风格统一）的落地版：检查器从右栏移到列表下方，列表成为唯一主视图。**alpha 阶段，未做真机全流程点验**。

> 版本号说明：`v1.2.0-alpha2` 已于 2026-11-16 发布（tag 指 `ec0f4d7`，在本版提交之前），本版按严格递增规则使用 `1.2.0-alpha3`，不复用 alpha2。

### 界面

- **检查器改为底部抽屉**：与内容列同宽、压住表格底部；36px 头部（检查器 · 当前文件名 · 作用于 N 个文件 · 六段分段 · 收起 · 关闭），正文 200px，窗口高度 ≤760 时压到 150px 把高度还给表格。
- **列表是唯一主视图**：删除八类列表页签（原先按类型分列的只读视图），六类操作全部从抽屉分段直达；右栏只留规则链。
- **页头新增「清空列表」**：二次确认，明说只移出列表、磁盘上的文件不删除不修改；原「更多」菜单里的重复入口移除。
- **侧栏收敛**为「文件」一组（更名 / 操作记录 / 快照 / 方案）；设置改从工具栏「更多」进入。
- **工具栏** 9 个命令分四组、组间 16px；筛选 / 键盘快捷键 / 设置收进「更多」菜单；状态与选中计数并入底栏，独立状态栏删除。
- 快捷键仍只在悬停或键盘聚焦时以提示出现，按钮上不常驻快捷键字符。
- macOS 交回系统标题栏（`decorations: true`，不再自绘双标题栏），Windows 保留自绘标题栏但配色、圆角、间距与 macOS 同一套令牌。

### 验证

- `npm run build`（tsc --noEmit + vite build）：通过。
- `npm run test:e2e`：**263 通过 / 0 失败**（报告 `app/e2e/report.md`，截图 `app/e2e/screenshots/`）。
- `npm run tokens:check`：69 个设计令牌与 `design/tokens.lock.json` 一致。
- `npm run version:check`：1.2.0-alpha3，清单 5 处一致。
- 更新签名：两个安装包的 `.sig` 用 `tauri.conf.json` 内置公钥离线复核（Ed25519，keyid `a1d8edb60bbc50fd`，trusted comment 绑定 `file` + `version:1.2.0-alpha3`），文件签名与 trusted comment 签名双 PASS。

### 签名与密钥

- 更新签名私钥 `renomio-signing/renomio.key` 在仓库外目录，`.gitignore` 的 `*.key` 已覆盖；构建时只以路径注入 `TAURI_SIGNING_PRIVATE_KEY`，不复制、不打印、未进入安装包或仓库。
- Windows Authenticode **未签**（本机无 OV/EV 证书）：首次运行 SmartScreen 会提示「未知发布者」，属预期；`scripts/sign/windows-sign.ps1` 提供证书接入点，配好后可直接重签。
