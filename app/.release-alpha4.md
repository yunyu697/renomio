## Renomio 1.0.0-alpha4（预发布）

本版新增「规则链输入历史」。**alpha 阶段，未完成真机点验**。

### 功能

- **按字段分开保存**：`replace.find`、`replace.replace`、`add.text`、`delete.left/right/chars`、`number.expression`、`case.separators`、`ext.*`、`meta.separator` 各自独立，不混在一起。
- **条数与淘汰**：默认每字段 **50 条**，设置页可改 **10–200**；相同内容再次输入时**提到最前、不堆叠**；超过上限**淘汰最旧**；调小上限时每个字段只保留最新的 N 条。
- **记录时机**：输入框失焦且内容确实被改过才记录（避免把未编辑的默认值塞进历史）。
- **管理**：输入框右侧 `▾` 打开历史列表；支持单条 `×` 删除；「清空」为**两步确认**；设置页另有「清空全部历史」（同样二次确认）。
- **键盘**：`↓`/`↑` 打开并移动选中，`Enter` 采用，`Esc` 关闭（不冒泡到全局）。
- **持久化**：写入应用数据目录的 `rule-history.json`（`%APPDATA%\app.renomio.desktop\rule-history.json`），原子写入（临时文件 → fsync → 改名），坏 JSON 会被改名为 `.json.bad` 并按空历史启动。安装目录之外，**升级 / 覆盖安装后保留**。

### 验证

- `npm run test:history`：**26 条**逻辑断言（去重前置、淘汰最旧、上限夹取、调小保留最新、坏数据归一化），已接入 CI frontend job。
- 浏览器实测（演示模式，localStorage 路径）：输入 `abc` 失焦后出现历史入口；列表读取为 `abc`；`↓`+`Enter` 能把历史值回填到查找框。
- 未验：桌面端 `rule-history.json` 的实际落盘（需开窗运行安装包，见下）。

### 需要真机确认的步骤

1. 安装本包，打开「设置 → 规则链输入历史」，确认上限显示 50；
2. 在规则链「替换」的查找框输入内容后点到别处，右侧出现 `▾`；
3. 关闭应用再打开，历史仍在；
4. 打开 `%APPDATA%\app.renomio.desktop\rule-history.json` 确认文件存在且按字段分组。
