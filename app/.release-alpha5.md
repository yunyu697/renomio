## Renomio 1.0.0-alpha5（预发布）

本版新增「设置页检查更新」。**alpha 阶段，未完成真机点验**。

### 功能

- **三个动作**：`更新`（下载 → 校验签名 → 启动安装 → 自动重启）、`仅下载`（落到系统默认下载文件夹，完成后出现 `安装` 按钮）、`打开主页`。
- **加速镜像 + 自动回退**：可选「自动 / GitHub 官方 / ghproxy.net / gh-proxy.com / ghfast.top」；每个地址都按「所选镜像 → 官方」顺序逐个尝试，清单和安装包走同一套候选；签名失败也会换下一个源。
- **完整性**：以 Tauri updater 的 minisign 签名校验为准（内置公钥；私钥保存在仓库外，不入库、不进 CI）。清单声明的版本必须与签名里绑定的版本/文件名一致；镜像返回错文件或旧文件会被拒绝。
- **进度与失败**：下载进度按字节与百分比推送；失败原因按源逐条列出（HTTP 状态、网络错误、签名不匹配）；可 `重试`，可先换镜像再重试。
- **不留半截文件**：下载先写 `%TEMP%\renomio-update\*.part`，校验通过才改名/复制；失败或换源立即删除；应用启动时清理残留。
- **仅下载的安装**：下载目录同时写入 `<安装包>.sig` 旁挂签名；点 `安装` 会再次校验（内存记录丢失时读旁挂签名或重新拉清单）后才启动安装。
- **演示模式**：浏览器演示模式禁用更新按钮，并说明不会连接更新服务。

### 需要真机确认的步骤

1. 安装 **alpha4** 包（上一版），启动后打开「设置 → 检查更新」；
2. 点 `检查更新`，确认显示「发现新版本 1.0.0-alpha5」与来源；
3. 点 `更新` → 确认对话框 → 观察进度 → UAC 提示（若弹出请允许）→ 安装完成后应用自动重启；
4. 重启后「当前版本」应变为 `1.0.0-alpha5`；
5. 另测 `仅下载`：确认文件出现在 `%USERPROFILE%\Downloads`，按钮变为 `安装`；点 `安装` 同样应校验并重启；
6. 换源测试：把镜像切到不可用的源再重试，确认会自动回退到官方并可完成下载；
7. 错包拒收测试：临时把 `latest.json` 的 `url` 指向另一个版本的安装包（或用本地代理返回错误文件），确认提示「签名校验失败」且不启动安装。

### 已知限制

- 两个包均未代码签名；UAC 提示来自安装器的机器级安装。
- 自动安装/重启无法在无窗口环境中验证，需按上表真机点验。
