## 复现方式

```powershell
# 1) 带 CDP 端口拉起安装版（先关掉已在跑的实例）
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS = '--remote-debugging-port=9444 --remote-allow-origins=*'
Start-Process "$env:LOCALAPPDATA\Programs\Renomio\renomio.exe"

# 2) 走完整更新链（检查 → 下载 → 验签 → 安装）
cd app\scripts\verify
node update-chain.mjs

# 3) 升级完成后再跑一次，只检查、应回「已是最新」
$env:CHECK_ONLY = '1'; node update-chain.mjs
```

脚本说明：`update-chain.mjs` 只通过 UI testid 操作（`update-check` / `update-action` / `update-confirm-yes`），「更多」按钮的 testid 兼容 `toolbar-more` 与 `toolbar-more-menu` 两代；结果写 `result.json`。
