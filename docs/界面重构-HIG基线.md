# Renomio 界面重构 · HIG 基线（B 方案）

> 生效日期：2026-11-24
> 依据：Apple Human Interface Guidelines（针对 macOS 设计 / 窗口 / 工具栏 / 边栏）
> 方向：**B 方案——以 macOS 风格为基准，Windows / Linux 保留平台习惯，但三平台共用同一套视觉与结构规格。**
> 范围：界面结构与交互层。签名、发布链不在本文范围。

## 1. 立场

Renomio 是跨平台批量更名工具，不是 macOS 独占 App。因此采用「**一套结构 + 平台外壳差异**」：

- **结构统一**：窗口内容区怎么分层、工具栏怎么分组、底栏放什么、面板怎么收放，三平台完全一致。
- **外壳分平台**：标题栏与菜单交给系统（macOS），Windows 用无渐变自绘条 + 系统窗口按钮，Linux 与 Windows 同构。
- **语言统一**：控件规格、间距、字号、圆角只有一套，不因平台改观感。

不做的事：不复制 macOS 专属材质（Liquid Glass / 毛玻璃），不引入平台语义色之外的品牌色，不为了「像 Mac」牺牲 Windows 的可发现性（例如右键菜单、双击行为）。

## 2. 窗口（window）

| 规则 | 落地 |
| --- | --- |
| 不创建自定义窗口框架与窗口控制 | macOS 走系统原生标题栏（`decorations: true`），前端不再渲染自绘条 |
| 标题回答「这是哪个 App / 哪个视图」 | Windows 自绘条只放 BrandMark + 产品名，≤15 字符，不放状态 |
| 标题栏不承载状态 | 规则数量、预览模式、版本号一律移出标题栏 |
| 关键操作不放底栏 / 侧边栏底部 | 设置从侧边栏底部改为菜单入口 |
| 底栏只放与选中项直接相关的少量信息 | 只留「已选 N 项 · 批次状态」+ 三个动作 |

## 3. 工具栏与命令（toolbar）

- **分区**：组内间距 8px、组间 16px，用留白分组，不用竖线切分。
- **分组顺序**：加入内容 → 方案（导入/保存）→ 批次历史（撤销/恢复顺序）→ 读取与导出 → 搜索 → 更多。
- **低频命令进「更多」**：筛选跳转、快捷键帮助、设置收进末尾 ⋯ 菜单；工具栏不出现第二排。
- **溢出策略**：只保留一行；宽度不足时按钮降级为图标（`data-fold="icons"`），不折行、不压缩控件高度。
- **禁止**：同一命令在工具栏出现两次；把相斥命令（撤销/重做）做成两个同权大按钮。

## 4. 导航与面板（sidebar / split view）

- 侧边栏不超过两层分组，组标题短；选中态用整行圆角胶囊，不用左侧竖条。
- 侧边栏底部不放关键操作（用户移动窗口时会挡住）。
- 拆分视图：主区 + 右栏（规则链）。右栏可拖宽、可折叠。
- **折叠态不得竖排文字**：规则链收起时是 48px 图标轨，只显示计数徽标与恢复按钮。
- 视图切换、扫描选项等「一次性设置」不常驻主界面行；能收进菜单的就收。

## 5. 信息密度与底栏

- 一屏只允许一条工具栏 + 一条路径/过滤行 + 一条底栏；出现第三、第四条横带即为不合格。
- 路径 / 过滤行单行显示：路径过长时省略，不折行；缩到 1280px 以下隐藏开关标签、保留开关本体（悬停给全称）。
- 对象数量、文件夹数量这类派生统计归入底栏或检查器，不重复出现在两处。
- 版本号、平台标识、数据目录：进设置 → 关于，主界面不显示。

## 6. 文字与色彩

- 字号只用令牌档位（10/11/12/14/16/20/24），不得出现 11.5、13.5 这类半档。
- 正文基准沿用 compact 档 12px，但**表格行与对话框正文不得低于 12px**；表头、时间戳用 11px caption。
- 强调色只用语义色（`--ds-color-accent`），不硬编码品牌蓝到控件；深浅两套色板必须同源映射。
- 圆角按角色取：控件 8、卡片 10、面板 14、徽标 4，同一层级内不得混档。

## 7. 控件与命中

- 可点目标 ≥28×28（指针设备同样适用）；竖排窄条、20px 高度控件不得承载功能入口。
- 标准控件优先：按钮 / 分段控件 / 开关 / 弹出菜单 / 表格；自定义弹层沿用同一套面板语言（1px 描边 + elevation-3 + 8px 内边距）。
- 键盘可达：每个工具栏命令都能在「更多」菜单或快捷键里找到同义项；弹层支持 Esc 关闭、点外部关闭。

## 8. 跨平台差异表

| 项 | macOS | Windows / Linux |
| --- | --- | --- |
| 标题栏 | 系统原生（红绿灯、系统标题） | 自绘 40px 平底，BrandMark + 产品名 |
| 窗口控制 | 系统提供 | 自绘 -/□/×，hover 高亮，close 红 |
| 菜单 | 系统菜单栏（后续接入 Tauri menu） | 「更多」菜单承担同等命令集 |
| 拖拽区域 | 原生标题栏 | 自绘条整行可拖 |
| 侧边栏 / 右栏 / 底栏 | 与 Windows 完全一致 | 与 macOS 完全一致 |

## 9. 验收清单

结构性（可自动化）：

- [ ] 一屏只有一条工具栏、一条路径行、一条底栏（DOM 层统计可见横带数量）
- [ ] 工具栏单行不折行，1100×640@150% 下无裁切
- [ ] 「更多」菜单可开可关，Esc / 点外部均能关闭
- [ ] 每个工具栏命令都有菜单或快捷键出口（命令可达性对照表）
- [ ] 规则链折叠态无竖排文字，徽标可读
- [ ] 主界面不出现版本号、平台标识

手感类（需真机点检，E2E 覆盖不到）：

- [ ] 1400×900 与 1100×640 两档下，路径行不折行、不挤压主表
- [ ] 深浅主题切换后，底栏与工具栏的边界仍可辨识
- [ ] 右栏拖宽到极值时不遮挡主表操作按钮
